# Domain docs

Sandboxer is a single-context repository.

Before exploring or changing the system, read:

- `CONTEXT.md` for the ubiquitous language;
- relevant decisions under `docs/adr/`.

Use the canonical terms from `CONTEXT.md` in issues, specs, APIs, tests, and
reports. Avoid synonyms explicitly rejected by the glossary. If work conflicts
with an ADR, identify the conflict rather than silently overriding it.
