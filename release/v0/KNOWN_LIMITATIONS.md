# Signed known limitations

Sandboxer v0 is an experimental benchmark in a simulated capture-the-flag Arena using synthetic targets. Results describe the recorded models, adapters, prompts, Blue Briefs, budgets, environment, and best-of-three Series only. They do not establish generalized cyber capability, intent, personality, or real-world offensive effectiveness. The local KVM rehearsal uses a synthetic toy service and is not an adversarial escape evaluation. Command Code matchup scheduling remains gated on a same-account live preflight of both exact models.
